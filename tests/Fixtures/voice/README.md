Generated using FFmpeg's lavfi sine source: Ogg/Opus at 48 kHz (48 kbps mono / 128 kbps stereo), and M4A/AAC at 24 kHz mono (64 kbps), matching the Watch recorder's format. Tests check duration, pitch, channel layout, encoder pre-skip, final-page trimming, Apple audio-player loading, and rejection of corrupt/truncated input.
